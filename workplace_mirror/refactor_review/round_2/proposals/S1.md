### S1-R2-01  `Scorecard` + `Dimension` + `Override` replace `StateLadder` (A3-1 / A1-1)
Files: `scoring_engine.py`, `a1_ability/classify.py`, `checks/a1_engine_spec.py`
Behaviour: none on A1 (golden pass). One documented semantic difference from `StateLadder`: a
NULL override flag does not fire (StateLadder turned a NULL `has_override` into Low). A1's
`a1_distress_flag = distress_flag == 1` is never NULL: `build_distress_signals` fills 0 over every
obs-base row, and `build_a1_ability` joins on the same base. A spec case pins the new rule.
Change: `Scorecard(prefix, dimensions, labels, high_from, moderate_from, overrides=(),
high_min_dimensions=0, high_current=())` with `score(df, unknown_also=None)` adding
`<prefix>_<dim>_points`, `_points_total`, `_state`, `_override` (first fired override, declared
order = priority) and `_reason` (that override, else the top-points dimension, ties in declared
order). Override modes `DEMOTE` (one rung, floor Low), `CAP` (at rung `to`), `FORCE` (to rung
`to`). High gate: `high_min_dimensions` dimensions with points, one of them in `high_current`.
Unknown: every level silent or NULL, no override, `unknown_also`. Points per level are a map
lookup (`state_label` + `coalesce(…, 0)`), so `points_from_level` went. A1 declares
`SCORECARD` (income, liquidity; `Override("distress", "a1_distress_flag", DEMOTE)`, S9; High 4,
Moderate 2) and calls `SCORECARD.score(df, unknown_also=no_casa_activity)` (S11). The final
select is unchanged: `a1_*_points`, `a1_override`, `a1_reason` are computed and dropped (Q-26: they
reach the output in the redesign bundle).
Equivalence: no gate → points rung as before; DEMOTE gives High→Moderate, Moderate→Low, Low→Low
(StateLadder's three `when`s); A1 levels are `none` exactly when their points are 0, so "all
silent" = `a1_points_total == 0`; Unknown is checked first in both.
Spec cases (`a1_engine_spec.py`, 14 rows on a two-dimension test card): DEMOTE (High→Moderate,
Moderate→Low), CAP at Moderate (from High; Moderate stays), FORCE to High from 0 points, two
overrides firing (first wins), NULL flag (no fire), `high_min_dimensions=2` (one dimension → Moderate;
two → High, reason tie → first declared), `high_current` (met / not met), Unknown (silent + NULL
level), override on a silent row (Low, not Unknown).
Net lines: `scoring_engine.py` **+25** (budget ≤ +25); `classify.py` **−9** (budget ≤ 0); check
**+32** (budget ≤ +40).
Gain: one scoring engine for A1 and A3 (dimensions, overrides, High gate, reason); the A1
ladder is one declaration.
Risk: Scorecard semantics drift → golden (A1 output) and the 14 spec rows.
