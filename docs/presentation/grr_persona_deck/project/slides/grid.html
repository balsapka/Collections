This is the core of the framework. Rows are ability, columns credibility, each split three ways including an honest unseen. The four corners need four different conversations: willing and able customers need a reminder and a payment link; able but not paying customers need firmness and early escalation; customers who pay while stretched need a sustainable plan; unable and not paying customers are recovery and provisioning cases. The unseen row is our data gap: decisions there should start with getting evidence. Each cell carries two overlays: how to reach them and how they got here.
