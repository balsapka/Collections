How it is built

Built to be explained and trusted

Rules you can trace

Every state comes from a written rule, and the record says which rule assigned it and why.

Unknown is a state

When evidence is missing we say so, with the reason, instead of guessing.

Point in time

Each month end uses only what was known that day: the view a strategy would have had.

Customer-level evidence

Salary, CASA, bounces and logins are read across all of a customer's accounts, not only the delinquent one.

6

Four design choices, each made for adoption. Rules rather than a model, so every state can be traced to the rule that assigned it. Unknown as an explicit state with a reason, which doubles as our map of data gaps. Point-in-time month ends, so any back-test is fair. And customer-level evidence across all accounts.
